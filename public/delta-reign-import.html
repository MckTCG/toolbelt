How the import works

  • Uses the exact same tcg-lab-card-db-v0.1 browser storage key as Card DB and Deck Builder.
  • Automatically downloads a complete backup of your existing Card DB records before any changes.
  • Creates or reuses the TEMP — Delta Reign set, keeping existing custom TEMP sets, cards and tags.
  • Skips previously imported Delta Reign IDs and known matching cards in an existing Delta Reign set. Safe to run again.
  • Does not import 22 supplementary deck cards again; existing catalog records cover those card names.
  • Artwork URLs and translated summaries are provisional. Check the card image before printing.

Seeing broken Delta Reign pictures? Audit all 113 artwork links and safely repair supported Japanese-image fallbacks. Run it in the same browser as your Card DB.
